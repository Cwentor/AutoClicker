# auto_clicker 连点器

## 项目简介

auto_clicker 是一款简单易用的鼠标连点器工具，能够帮助用户自动执行鼠标点击操作，适用于各种需要重复点击的场景，如游戏、数据录入等。

- **版本号**: v1.0
- **开发语言**: Python
- **界面**: 图形化界面 (Tkinter)

## 功能特点

- ✅ 可自定义点击间隔（秒）
- ✅ 支持选择鼠标左键或右键点击
- ✅ 快捷键控制（开始/暂停、停止）
- ✅ 多线程设计，确保界面流畅不卡顿
- ✅ 美观的图形化界面
- ✅ 窗口居中显示
- ✅ 简单易用的操作方式

## 安装说明

### 前置条件

- Python 3.6 或更高版本

### 安装依赖

打开命令提示符，进入项目目录，执行以下命令安装所需依赖：

```bash
pip install -r requirements.txt
```

## 使用方法

1. **启动程序**：在项目目录中执行以下命令
   ```bash
   python auto_clicker.py
   ```

2. **设置点击间隔**：在界面的"点击间隔"输入框中输入所需的点击间隔时间（单位：秒），例如输入 `0.1` 表示每0.1秒点击一次。

3. **选择点击按钮**：在"点击按钮"区域选择需要使用的鼠标按钮（左键或右键）。

4. **开始/暂停连点**：按下快捷键 `CTRL+ALT` 开始或暂停连点操作。

5. **停止程序**：按下快捷键 `ALT+Q` 停止连点并退出程序，或直接关闭窗口。

## 快捷键说明

| 快捷键      | 功能                |
|------------|--------------------|
| `CTRL+ALT` | 开始/暂停连点       |
| `ALT+Q`    | 停止程序            |

## 依赖项

- **pyautogui**: 用于模拟鼠标点击操作
- **keyboard**: 用于监听和处理键盘快捷键
- **tkinter**: 用于创建图形化界面（Python标准库，无需单独安装）
- **threading**: 用于实现多线程操作（Python标准库，无需单独安装）
- **time**: 用于控制时间间隔（Python标准库，无需单独安装）

## 注意事项

1. **使用安全**：请合理使用本工具，不要用于任何违反法律法规或游戏规则的场景。

2. **防检测**：某些游戏或应用程序可能会检测自动点击行为，使用时请自行承担风险。

3. **性能影响**：设置过短的点击间隔可能会对系统性能造成一定影响，建议根据实际需求合理设置。

4. **权限要求**：在某些系统环境下，可能需要以管理员权限运行程序才能正常使用快捷键功能。

5. **退出方式**：建议使用 `ALT+Q` 快捷键或直接关闭窗口来退出程序，以确保所有资源被正确释放。

## 界面预览

程序启动后会显示如下界面：

- 顶部显示程序标题
- 中间区域可设置点击间隔和选择点击按钮
- 底部显示快捷键提示信息

## 故障排除

### 快捷键不生效

- 确保程序窗口处于活动状态
- 尝试以管理员权限运行程序
- 检查是否有其他程序占用了相同的快捷键

### 点击操作不执行

- 确保已按下 `CTRL+ALT` 开始连点
- 检查点击间隔设置是否合理
- 确保鼠标指针位于需要点击的位置
